# Pitch Perception

The published files of [Pitch Perception](https://pitchperception.app), an independent, non-commercial
model of MLS player value. Not affiliated with or endorsed by Major League Soccer.

This repository holds the built site only. Its history timestamps every update, including the live forecast record
(`data/forecast_log.csv`): each forecast appears in a commit before its match kicks off.

Contact: MLSPitchPerception@gmail.com, or @MLSPerception on X.
